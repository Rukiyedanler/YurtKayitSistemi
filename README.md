       Yurt Kayıt Sistemi

Yurt Kayıt Sistemi, öğrenci yurtlarında kayıt, ödeme ve yönetim işlemlerini kolaylaştırmak amacıyla geliştirilmiş bir otomasyon uygulamasıdır. Bu proje sayesinde öğrencilerin bilgileri düzenli bir şekilde tutulur ve yönetim işlemleri hızlı bir şekilde gerçekleştirilir.

       Proje Amacı

Bu projenin amacı:

Öğrenci kayıt işlemlerini dijital ortama taşımak
Yurt yönetimini kolaylaştırmak
Ödeme ve gider takibini sistematik hale getirmek
Verileri güvenli ve düzenli bir şekilde saklamak

 Kurulum
Bu projeyi klonlayın:
git clone https://github.com/kullaniciadi/yurt-kayit-sistemi.git
Visual Studio ile açın
SQL Server üzerinde veritabanını oluşturun
App.config dosyasından bağlantı ayarlarını yapın
Projeyi çalıştırın
     Güvenlik
Kullanıcı giriş sistemi mevcuttur
